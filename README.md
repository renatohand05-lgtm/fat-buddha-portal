# Fat Buddha · Portal Operacional

Site estático (HTML + JS) com banco Supabase (`fat-buddha-portal`, sa-east-1).

- `index.html`, `styles.css`, `js/`, `vendor/`, `logo.png`: portal publicado na Vercel (sem build).
- `supabase/migrations_ref/`: SQL aplicado no banco (schema, segurança/RLS, seed).
- `supabase/functions/admin-usuarios/`: função de gestão de usuários (somente administrador).
